# Ultron_V0.2 — Experimental / Research Prototype (Retired)

Second physical build (2025). Laboratory platform used to evaluate trade-offs
that Ultron_V0.3 formalizes (motor control, interrupt wiring, real-time ↔
Linux split, containerization, power budgeting). **Not** a reference design
for deployment.

See [`history.md`](history.md) for the full record. For the current build,
always follow the [`../V0.3_Ultron/implementation_bible.md`](../V0.3_Ultron/implementation_bible.md).
