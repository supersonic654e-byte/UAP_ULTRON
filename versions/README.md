# Versions

Each robot generation lives in its own folder. **Retired versions are
read-only history**; active work happens in `V0.3_Ultron/` and up.

| Folder | Status | Contents |
|---|---|---|
| `V0.1_Ultron/` | Retired (2024) | Lab/learning prototype history |
| `V0.2_Ultron/` | Retired (2025) | Research prototype history |
| `V0.3_Ultron/` | **Active** | Current build — implementation Bible + hardware/firmware/software/tests |
| `InsightV1.0_Ultron/` | Planned | First real-world deployment — spec + hardware upgrade + deployment plan |
| `_future/` | Planned | VitalsV2.0 / MedAssistV3.0 roadmap |

Naming is canonical — see `docs/00_project/naming_and_versioning.md`.
