# Reference

Shared, version-independent reference material.

| Doc | Purpose |
|---|---|
| `BOM_shared.md` | Cross-version bill of materials (parts reused across generations) |
| `datasheets/` | Drop manufacturer datasheets here (named: `part-datasheet.pdf`) |
| `CAD/` | Shared mechanical parts (native files + STL) |

> Component data sheets are large binary files — keep them in Git LFS or attach
> links instead of bloating the repo.
